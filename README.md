# Pets corp site

## Install

- `yarn build`

## Stack tec

- nodejs, yarn
- nextjs, MUI5

## Scripts

- `yarn import:data` — импорт данных из `import_data/data.xlsx` и (опционально) загрузка изображений.
- `yarn update:imgs` — обновляет `img1..img10` из поля `imgs`.
- `yarn admin:seed` — создаёт админов из `ADMIN_USERS` в `.env`/`.env.poduction`.
